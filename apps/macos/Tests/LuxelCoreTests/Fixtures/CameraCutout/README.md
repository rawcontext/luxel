# Camera Cutout Portrait Fixture

`loral-ohara-portrait.jpg.base64` is a reduced test copy of NASA photo
JSC2017-E-114808, an official portrait of astronaut Loral O'Hara photographed
by NASA/Bill Stafford. The source image is a work of the United States federal
government and is in the public domain in the United States. The fixture was
resized and JPEG-compressed for the test suite, then stored as Base64 so it can
be reviewed as text.

Source: https://commons.wikimedia.org/wiki/File:Loral_O%27Hara_official_portrait.jpg

The portrait exercises hair detail, fingers at the foreground boundary,
partial-body framing, and similar blue foreground/background colors.
