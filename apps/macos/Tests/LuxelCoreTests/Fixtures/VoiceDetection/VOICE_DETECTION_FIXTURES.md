# Voice Detection Fixtures

This directory is the only test fixture location where Luxel stores audio. Run
`Scripts/generate-voice-detection-fixtures.sh` from any directory to regenerate
the corpus and `manifest.json`.

The genuine speech source is LibriSpeech dev-clean recording
`1272-128104-0000`, obtained through Hugging Face's LibriSpeech ASR dummy
dataset. LibriSpeech is derived from LibriVox recordings and distributed under
CC BY 4.0. The recording ID, transcript, source URLs, consent/license basis,
format, duration, expected benchmark behavior, and checksum are recorded in the
manifest.

Every other signal is either derived from that licensed speech fixture or is a
deterministic synthetic waveform generated by the checked-in script. No Luxel
user audio is present. The benchmark consumes these files offline and does not
log samples or per-frame probabilities.
