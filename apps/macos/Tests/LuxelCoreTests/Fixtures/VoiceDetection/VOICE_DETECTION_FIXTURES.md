# Voice Detection Fixtures

This directory is the only test fixture location where Luxel stores audio. Run
`Scripts/generate-voice-detection-fixtures.sh` from any directory to regenerate
the corpus and `manifest.json`.

The genuine speech source is LibriSpeech dev-clean recording
`1272-128104-0000`, obtained through Hugging Face's LibriSpeech ASR dummy
dataset. LibriSpeech is derived from LibriVox recordings and distributed under
CC BY 4.0. The recording ID, transcript, source URLs, consent/license basis,
format, duration, expected benchmark behavior, and checksum are recorded in the
manifest.

The generator accepts the row only when Hugging Face returns [dataset revision
`5be91486e11a2d616f4ec5db8d3fd248585ac07a`](https://huggingface.co/datasets/hf-internal-testing/librispeech_asr_dummy/tree/5be91486e11a2d616f4ec5db8d3fd248585ac07a).
It then verifies the downloaded
120,041-byte FLAC against SHA-256
`4e25e22555cd16e90edb0a3b49fdcf1fe652b2a1250ab643634db33895c75b41`
before conversion. The signed cached-asset query is temporary, so the manifest
records its stable revision-qualified path instead of the expiring signature.

Use the Python version in the repository's `.tool-versions` and [FFmpeg
8.1.2](https://ffmpeg.org/releases/ffmpeg-8.1.2.tar.xz).
The generator fails closed when either version differs. FFmpeg 8.1.2 remains
the fixture converter because FFmpeg 9.0.1 writes different WAV bytes for the
same FLAC; retaining 8.1.2 keeps the checked-in offline regression corpus exact.

Every other signal is either derived from that licensed speech fixture or is a
deterministic synthetic waveform generated by the checked-in script. No Luxel
user audio is present. The benchmark consumes these files offline and does not
log samples or per-frame probabilities.
